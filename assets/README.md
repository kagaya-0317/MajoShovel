# Assets

Put original or properly licensed image/audio assets here, and document source/license information beside them.

The renderer does not load a shared icon sprite sheet. Object images are drawn from `assets/objects/obj_*.png`.
System images are stored under `assets/system/`, including UI images (`UI_*.png`) and renderer support images such as `crack.png`.
`assets/system/UI_protectionLock.png` was supplied by the repository owner for use as the protected-item marker (original filename: `カギの閉じた錠のアイコン素材 3.png`).
Character sprites are stored under `assets/characters/`.
