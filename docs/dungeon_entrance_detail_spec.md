# ダンジョン入口 詳細ウィンドウ仕様

## 目的

拠点のダンジョン入口画面で、選択中ダンジョンの特徴を右側詳細ウィンドウに表示する。
出発操作とダンジョン情報を同じ画面で確認できるようにし、発見済みワープポイント表示は左側のダンジョン名下から詳細ウィンドウへ移す。

## レイアウト

- ダンジョン入口画面は横長のメインウィンドウを使う。
- 左側に行き先選択と出発地点選択を置く。
- 行き先選択の下には共通の横区切り線画像を表示する。
- 出発地点選択の見出しは `どこから採掘を開始する？` とする。
- 右側には他の拠点UIと同じ `drawUiSubPanel` ベースの詳細ウィンドウを置く。
- メインウィンドウは詳細ウィンドウ追加後の初期実装から横幅を 192px 縮め、左側の操作領域を圧縮する。
- 詳細ウィンドウは初期実装から横幅を 48px 広げる。
- ローグライクダンジョン選択時は出発地点選択を省き、左側の操作ボタンは `出発` のみ表示する。
- ローグライクダンジョンの `出発` を押した時は、特殊ルールを箇条書きで示す確認ウィンドウを出し、`いいえ` / `はい` で出発を確定する。
- ワープポイント選択ウィンドウの各ボタンは `ワープ1（123m）` のように、ワープ番号とメインルート上の深度を表示する。
- ワープポイント選択ウィンドウの見出しは `どのワープポイントにする？` とし、通常の出発地点選択見出しより 8px 下げて表示する。
- ワープポイント選択ウィンドウには右上の閉じるボタンを表示し、深度表示が収まるようにボタンとウィンドウ幅を広げる。
- アイコン付きテキストのボタンは、文字とアイコンが同じ行の中央に揃うように表示する。

## 詳細ウィンドウの表示順

1. ダンジョンのイメージ図
2. 説明文
3. 発見済みワープポイント
4. 難易度
5. 広さ
6. 壁の固さ
7. 地形の複雑さ
8. 出現する敵

## 表示内容

- ダンジョンのイメージ図は高さ約 96px の小さな図として表示する。
- `StageDefinition::detail.imagePath` が設定されている場合はその画像を表示する。
- 既定ステージの画像は `assets/stages/detail/*.png` に置き、Google Sheet 側の画像指定が空の場合はステージIDに応じた既定画像を使う。
- 画像パスが空、または読み込めない場合はステージの地形プロファイルに応じた簡易イメージ図を描画する。
- 説明文は 2 から 3 行を想定する。
- ローグライクダンジョンの説明文には「持ち込み不可」「初期ステータスから開始」の趣旨を含める。
- 発見済みワープポイントはワープアイコン付きで `発見済み/総数` を表示する。
- ワープポイントが存在しないダンジョンは `0/0` を表示する。
- 出現する敵は `StageDefinition::detail.enemyIds` の順に画像アイコンで表示する。
- `enemyIds` が空の場合は、既存のステージ別敵出現 weight から出現候補を収集して表示する。
- 図鑑で未発見の敵は黒寄りのシルエット表示にする。
- 出現する敵の一覧にはスロット背景の四角を描かず、敵画像またはシルエットだけを約 43px のサイズで狭い間隔に並べる。

## 表示用データ

`StageDefinition::detail` に以下の表示専用データを持たせる。

- `imagePath`
- `description`
- `difficulty`
- `size`
- `wallHardness`
- `terrainComplexity`
- `enemyIds`

Google Sheet の `Stages` では以下の任意列を読み込める。

- `詳細画像` / `detail_image_path`
- `詳細説明` / `detail_description`
- `難易度` / `detail_difficulty`
- `広さ` / `detail_size`
- `壁の固さ` / `detail_wall_hardness`
- `地形の複雑さ` / `detail_terrain_complexity`
- `出現する敵` / `detail_enemy_ids`

列が存在しない場合、既存のステージ定義と生成パラメータからフォールバック表示を作る。

## ラベル

- 難易度: `やさしい` / `ふつう` / `むずかしい` / `不明`
- 広さ: `広くない` / `広い` / `かなり広い` / `底なし`
- 壁の固さ: `やわらかめ` / `ふつう` / `かため` / `不明`
- 地形の複雑さ: `そこまで` / `少し` / `複雑` / `不明`
