# ストーリーステージ仮想火力・敵HP設計基準

更新日: 2026-08-03

## 位置づけ

この文書を、ストーリーステージ1～3の通常敵HPを設計する際の仮想火力の正とする。

`enemy_hp_balance_report.md`、`stage_depth_hp_baseline.csv`、`enemy_hp_recommendations.csv` にある旧計算は、単品攻撃力の中央値と想定命中回数を基準にした過去資料であり、今後のストーリーステージHP調整の基準には使用しない。

## 仮想火力の定義

仮想火力は、その進行地点で想定する理想的なリング編成の全アイテムが、敵へそれぞれ1回ずつ基礎接触ダメージを与えたときの合計攻撃力とする。

- ステージ1開始時はリング1のみ使用できる。
- ステージ2開始前にリング2が解禁される。
- ステージ3開始前にリング3が解禁される。
- レベルアップ回数の約1/3をリング重量強化へ使用する想定を含む。
- 理想編成は、アイテム個数基準で採掘道具30%、武器20%、防具10%、探索道具20%、その他20%を目安とする。
- 杖はリング外装備のため、編成比率と仮想火力には含めない。
- 魔法発動、状態異常、会心、速度補正、加工強化、耐性、ガードは仮想火力そのものには含めず、敵ごとの実効耐久補正で別に扱う。

## 敵HP決定方針（検討案）

### 基本式

通常敵のHPは、まず実効耐久の目標を決め、ガードや耐性を持つ敵だけ生HPへ逆算する。

`目標実効耐久 = 実質初出地点の仮想火力 × 役割係数`

`設定HP = 目標実効耐久 ÷ 防御による実効耐久倍率`

ここでいう実質初出地点は、抽選重み1などのごく低確率な先行出現ではなく、その敵が通常のプレイで認識される最初の抽選層を指す。目安として抽選重み5以上の最初の層を使い、全層で5未満の希少敵は最初の出現層を使う。

### 役割係数の初期案

| 役割 | 目標実効耐久係数 | 意図 |
|---|---:|---|
| 群れ・極小・一時的な雑魚 | 0.45～0.60 | 複数体を1周以内で処理できる |
| 高速・遠距離・逃走・自爆 | 0.60～0.75 | 当てにくさ、危険行動をHPと二重評価しない |
| 回復・妨害などの支援役 | 0.65～0.80 | 優先して倒せる余地を残す |
| 標準敵 | 0.85～1.00 | リング全体を概ね1周当てて倒す |
| 重量級・待ち伏せ・強敵 | 1.00～1.20 | 1周を少し超える耐久を持たせる |
| 盾・高耐性・明確なタンク | 1.10～1.35 | ガード・耐性込みの実効耐久で合わせる |

盾、正面ガード、物理耐性、魔法耐性などを持つ敵は、役割係数を掛けた後のHPをそのまま設定しない。平均的な攻撃属性とガード稼働率から実効耐久倍率を見積もり、その分だけ設定HPを下げる。防御能力と生HPを両方最大にして二重に硬くしない。

### 同じ敵が後半にも出現する場合

原則として、敵の基礎HPは実質初出地点で決める。後半層でも同じ敵を仮想火力と完全同期させて強化せず、既知の敵が相対的に倒しやすくなることを許容する。後半でも1周前後の耐久が必要な役割には、上位種または別敵を使用する。

同一個体が出現位置だけで大幅にHP上昇する進行度スケーリングは、敵の手触りが不透明になるため初期案では採用しない。実質初出基準で不足する場合にのみ、抽選層ごとの小さな補正を別途検討する。

### 丸め

- HP100未満: 1または5単位で読みやすく丸める。
- HP100以上300未満: 5または10単位で丸める。
- HP300以上: 10または20単位で丸める。
- 係数計算の小数をそのままデータへ残さず、敵同士の相対関係を確認してから最終値を決める。

### 対象外

ボスHPはこの通常敵用計算で確定しない。想定戦闘時間、フェーズ数、攻撃可能時間、ギミック成功回数から別に決める。不可思議の迷宮も、ストーリーステージ1～3の仮想火力をそのまま流用せず、深度別の編成成長を別途定義する。

## 調整手順

1. Enemiesシートの各敵について実質初出抽選層を決める。
2. 敵の行動とタグから役割係数を1つ決める。
3. ガード・耐性を持つ敵は実効耐久倍率を見積もる。
4. 基本式からHP初期案を出し、読みやすい値へ丸める。
5. 各抽選層の重み付き平均HPと最小・最大HPを確認する。
6. 標準敵が概ね1周、群れ敵が半周前後、重量級が1周強になるか実プレイで確認する。
7. 現在のテストセーブなど、理想編成より火力が低い実データでも極端に長期戦にならないか確認する。
