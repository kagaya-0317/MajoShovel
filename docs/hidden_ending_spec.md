# 隠し鬱エンド仕様

## 概要

隠し鬱エンドは、捕獲したモンスターをリング上で破壊し続けたプレイヤーだけが入れる裏ルート。
通常の図鑑完成、正統シナリオクリアとは別扱いにし、信頼崩壊後はそれらの通常エンディングに失敗イベントを流す。ローグライク踏破エンディングは信頼崩壊による失敗分岐を行わない。

## 解禁条件

- ストーリーダンジョン1～3面それぞれで、ステージクリア前に捕獲モンスターをリング上で累計100回以上破壊する。
- 条件達成後に通常ステージから拠点へ戻ると `story_hidden_orbit_corruption_unlocked` が立つ。
- 解禁後は拠点でもリングが常時回り、拠点NPCへの攻撃と虫取りアミ捕獲が可能になる。
- この時点でモニカは拠点から姿を消す。

## 信頼崩壊

- 拠点NPCまたは隠しルート中のダンジョンNPCを攻撃、捕獲、撃破した時点で `story_trust_broken` が立つ。
- 信頼崩壊後は正統エンド、図鑑コンプリートエンドが通常再生されず、対応する失敗紙芝居へ分岐する。
- ローグライク踏破エンドは、信頼崩壊後でも通常の踏破紙芝居を再生する。

## 拠点NPC

- 対象は商人、加工職人、村長。モニカはこの段階では対象にしない。
- 撃破または捕獲したNPCは `hidden_npc_removed:<facilityId>` を保存し、そのセーブデータでは拠点から消える。
- 商人、加工職人、村長をすべて捕獲または撃破すると `story_hidden_monica_duel_unlocked` が立ち、モニカ決戦導入イベントをキューする。

## モニカ決戦

- モニカ決戦導入イベント後、拠点から内部ステージ `hidden_monica_duel` へ自動遷移する。
- `hidden_monica_duel` は通常のステージカタログには出さない実行時専用ステージ。
- ボスIDは `hidden_boss_monica`。
- 現時点の挙動は既存ボス出現、撃破演出、捕獲許可に乗せる仮実装とする。
- モニカを撃破または捕獲すると、ボス撃破演出後に `EndingKind::HiddenBad` の紙芝居へ移行する。
- 隠しエンド完了時に `story_hidden_ending_everything_orbits` と `hidden_ending_people_gone` を保存する。

## ダンジョンNPC

- 隠しルート中は、ダンジョンイベントの魔女とローグライク施設NPCも通常会話/施設UIではなく敵対対象になる。
- ダンジョンイベント魔女は発見後、以下の隠し敵IDとして敵システムに生成する。
  - 埋もれた魔女: `hidden_npc_buried_witch`
  - 荷物をなくした魔女: `hidden_npc_lost_baggage_witch`
  - 依頼魔女: `hidden_npc_item_request_witch`
  - 囲まれた魔女: `hidden_npc_surrounded_witch`
  - 寒がり魔女: `hidden_npc_cold_witch`
  - 重岩の魔女: `hidden_npc_heavy_rock_witch`
- ローグライク施設NPCは以下の隠し敵IDとして敵システムに生成する。
  - 野良商人: `hidden_npc_rogue_merchant`
  - 野良加工職人: `hidden_npc_rogue_processor`
  - 修練者: `hidden_npc_trainer`
- 撃破または捕獲された対象はそのラン中で通常イベント/施設として扱わない。

## 図鑑

- 隠しNPCと隠しモニカボスは `codex_hidden` タグを持つ。
- 虫眼鏡や使用効果では図鑑情報を記録できるが、通常の図鑑総数、コンプリート判定、セーブされた通常図鑑枠からは除外する。
- 通常プレイではこれらの枠は見えない。
