# 作業台仕様

## 概要

作業台は、アイテムの一括修理と強化を行う拠点施設。

作業台を調べると、最初にシンプルな選択画面を表示する。

- 一括修理
- 強化

## 一括修理

`一括修理` を選ぶと、費用なしで修理を実行する。

対象は以下のみ。

- バックパック内の個体アイテム
- リングに装備中のアイテム

倉庫内のアイテムは対象に含めない。

修理対象のアイテムは、現在耐久値を最大耐久値まで回復し、破損状態を解除する。
耐久値を持たないアイテム、耐久値が最大で破損していないアイテム、スタック品は変更しない。

修理後は、修理したアイテム数を結果表示する。
修理対象がない場合は、修理が必要なアイテムがないことを表示する。

## 強化

`強化` を選ぶと、従来の作業台のアイテム選択 UI に移動する。

個別アイテムのコマンドには、修理を表示しない。
修理は一括修理に統一する。

破損しているアイテムは、個別の強化・加工・強化リセットを実行できない。
破損しているアイテムを強化したい場合は、先に一括修理で破損状態を解除する。
