# 拠点の雲影演出仕様

## 対象

- 拠点の屋外エリアだけに、上空の雲が落とす影を常時表示する。
- 家の中では表示しない。
- 拠点編集モードでは、編集用表示の視認性を優先して雲影を表示しない。
- セーブデータには状態を保持せず、拠点の既存アニメーション時刻から表示位置を決定する。

## 素材

- `assets/kyoten/cloud_shadow.png` を雲影のアルファマスクとして使う。
- 素材サイズは 1024 × 1024 px とする。
- 影は広く不規則な形状と柔らかい半影を持ち、細かな粒状感や明確な雲の輪郭を出さない。
- 上下および左右の端は同一のアルファ値とし、繰り返し描画時に継ぎ目が発生しない素材とする。
- 最終的な濃さは素材へ焼き込まず、描画側の tint で一元管理する。

## 描画

- 画像は `TextureFilter::Linear` で読み込み、画面上では 1536 × 1536 px のタイルとして描画する。
- タイルを拠点マップ全体へ必要な枚数だけ並べ、マップ範囲でクリップする。
- 合成方式は通常アルファではなく乗算合成を使い、背景の色相と細部を保ったまま光量を下げる。
- tint は黒 `rgba(0, 0, 0, 220)` とし、素材アルファと組み合わせた最暗部では背景輝度を約49%残す。
- 施設と人物を描画した後、ストーリー固有の発光演出、スペルリング演出、HUDを描画する前に重ねる。
- これにより建物と人物には雲影が落ちる一方、魔法の光とUIは暗くならない。

## 移動とループ

- 右下方向へ一定速度で移動する。
- 横方向は約 4.27 px/秒、縦方向は約 1.71 px/秒とする。
- 表示位置はタイルサイズで剰余を取り、同じ画像を隙間なく並べ直すことで、位置の飛びやフェード切り替えなしに無限ループさせる。
- 既存の拠点アニメーション時刻が 3600 秒で折り返しても継ぎ目が出ないよう、3600 秒で各軸の移動量がタイルサイズの整数倍になる速度を使う。

## 性能要件

- 画像は既存の画像キャッシュから取得し、フレームごとの読み込みや画像生成を行わない。
- 1280 × 720 の拠点画面では最大4タイルの描画に収める。
- 粒子や雲影ごとの動的オブジェクトは生成しない。
