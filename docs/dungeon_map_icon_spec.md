# ダンジョン地図アイコン仕様

ダンジョンのミニマップと全画面の探索地図は、同じ記号体系で表示する。

## 表示条件

- 地形として地図に記録済みのタイル上にあるものだけを表示する。
- 完全な未踏破地点の宝箱、木箱、ドロップ、イベント、ワープポイントは表示しない。
- 開封済み宝箱、破壊済み木箱、回収済みドロップ、完了済みイベントは表示しない。

## ミニマップ枠

- ダンジョン中の左上ミニマップには `assets/UI_mapFrame.png` を枠として重ねて表示する。
- 枠画像の基準サイズは 200x200。ミニマップの中心に合わせ、ミニマップ径が縮む場合は同じ比率で縮小する。
- 描画順は、地図背景、地形、地図アイコン、枠、ワープ案内方向アイコンの順にする。
- 枠画像を読み込めない場合は、従来の円形境界線をフォールバック表示する。
- 全画面の探索地図オーバーレイにはこの枠を使わない。

## アイコン

- 魔女: 進行方向を向く、地図でよく使われる2枚羽の尖った矢印。
- 出口: ハシゴ形アイコン。最初の開始位置にある帰還地点だけに使う。
- ワープポイント: 発見済みは明るい水色の丸。未発見は暗めの青い丸。ハシゴ形にはしない。
- 敵: 赤い丸。ボスは少し大きい橙赤の丸。リングは付けない。
- 宝箱: 黄色い四角。
- 木箱: 茶色い四角。
- イベントオブジェクト: ピンクの丸。
- アイテム: 黄色い丸。
- お金: 黄色い小さい丸。
- 素材: 青緑色の小さい丸。
