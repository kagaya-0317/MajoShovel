# ローグライクダンジョン仕様

## 対象

- ステージ定義がローグライク扱いのダンジョンを対象にする。
- 現行対象は `stage_04_astral_mine` / 不可思議の迷宮。

## 開始時の初期化

- 拠点からローグライクダンジョンを開始する時は、通常ダンジョンの持ち込み復元を行わない。
- バッグ内アイテム、リング上アイテム、所持金は拠点側の状態を引き継がず、ワールド生成中に作るラン初期状態を使う。
- ラン初期状態は `initializeDefaultSpellRing()` による初期リング装備を基準にする。
  - 初期シャベルと初期松明をリングへ配置する。
  - 初期杖が利用可能な場合は装備状態にする。
- プレイヤーレベル、経験値、次レベル経験値はラン開始時にレベル1相当へ戻す。
- `runStartInventoryState_` は持ち込み復元前の拠点状態ではなく、このラン初期状態を記録する。

## 通常ダンジョンとの差分

- 通常ダンジョンは、拠点で持っていたバッグ、リング、所持金を `InventoryCarryState` として退避し、生成完了後に復元する。
- ローグライクダンジョンは、出発前の拠点所持品を帰還用スナップショットとして保持するが、生成完了後の持ち込み復元はスキップする。
- ワープポイント開始、既存ダンジョン状態の復元はローグライクでは使わず、毎回新規生成する。

## 知識持ち込み

- ローグライクのランダムなオブジェクト報酬は、本編側で入手済みとして記録されたアイテムIDだけを候補にする。
- ローグライクのランダムなオブジェクト報酬は、通常ステージの `ST_C1` などの宝箱抽選重み列ではなく、ローグライク専用のカテゴリ重みとObjectsの `基準レベル` / `ローグライク重み` / `ローグライク残存重み` を使う。
- 抽選順は、まず本編入手済み、虫眼鏡除外、ドロップ除外タグ、必要タグ、カテゴリ一致などの候補フィルタを適用し、その後に深度ランクの目標レベルとの距離で重みを減衰させる。
- 目標レベルは敵のローグライク基準レベル表と同じく、区分1から `3, 7, 11, 15, 20, 25, 30, 35, 40`、区分10以降は+5ずつ伸ばし、最大100にする。
- アイテム候補の実効重みは `ローグライク重み * exp(-0.5 * (abs(基準レベル - 目標レベル) / 10)^2)` を基本にする。目標レベルがアイテムの基準レベル以上の場合は、この値と `ローグライク残存重み` の大きい方を使う。
- 本編未入手のアイテムは重み計算前に候補から外れる。同カテゴリに基準レベル1の既知アイテムだけが残っている場合、基準レベル20相当の深度でも、そのカテゴリが選ばれればその既知アイテムだけが出る。
- カテゴリ内の候補が1種類だけなら、その候補が選ばれる。候補がないカテゴリはカテゴリ抽選から外し、全カテゴリで候補がない場合はアイテムを出さず警告ログだけを出す。
- `main_knowledge_v1 1` をマーカーとして保存し、`main_obtained_object <objectId>` をセーブする。ローグライク内で入手したアイテムはこの記録を増やさない。
- 旧セーブに `main_knowledge_v1` が無い場合は、既存のアイテム/宝図鑑エントリから初回移行する。
- 虫眼鏡 `item_magnifying_glass` はローグライク報酬候補から常に除外する。
- 虫とりアミ系アイテムは、上記の本編入手済み条件と通常の報酬重みに従って出現できる。
- ローグライク中は未発見のアイテム効果も通常どおり発動する。ただし発動しても `codex_effect` には追加せず、効果発見ポップアップも出さない。
- 効果発見イベントを渡さないため、未発見効果の初回発見保証もローグライク中は働かない。
- 敵は本編で会ったことがない種類も通常どおり出現する。
- ローグライク中の虫とりアミは、本編側で捕獲済みとして記録された敵IDだけを捕獲できる。
- `main_captured_enemy <enemyId>` をセーブし、ローグライク内で捕獲してもこの記録は増やさない。
- 深層/奈落個体の捕獲判定は、強化個体IDではなく元の通常敵IDが `main_captured_enemy` にあるかで判定する。
- 旧セーブに `main_knowledge_v1` が無い場合は、捕獲アイテムID `captured_` / `captured_deep_` / `captured_abyss_` から敵IDを復元して初回移行する。

## 壁硬度

- ローグライクダンジョンの壁HPには、通常の `壁種別の基礎HP * ステージ地形硬度倍率 * ローカル地形硬度` に加えて、深度ランクごとの壁硬度倍率を掛ける。
- 深度ランクはローグライクのセクションランクを使う。500mごとにエリアが進み、各エリア内は3セクションとして扱うため、エリアを跨いでも深度ランクはリセットしない。
- 壁硬度倍率は以下のアンカーを満たす。
  - ランク1は `1.0`。
  - ランク7はおおむね `2.0`。
  - ランク9はおおむね `2.2`。
  - ランク15はおおむね `2.8`。
  - ランク16以降は伸びを緩やかにし、`3.0` に漸近する。`3.0` 以上にはしない。
- 計算式は以下とする。
  - ランク1から7: `1.0 + (rank - 1) / 6.0`
  - ランク8から15: `2.0 + (rank - 7) * 0.1`
  - ランク16以降: `3.0 - (3.0 - 2.8) * exp(-(rank - 15) / 4.0)` を基本にし、丸めで `3.0` 以上にならないよう `3.0` 直下にクランプする。

## 死亡・結果

- 死亡時は `runStartInventoryState_` に復元し、ラン中に得たバッグ、リング、所持金の増分を失う。
- ダンジョン内で死亡した場合は、不可思議の迷宮に限らず `astralEchoStarCount_` を1つ増やす。ゲームオーバーまたは不可思議リザルトでは、この直近の星だけ赤く表示し、以後は白い星として残す。
- 死亡演出完了後、すぐにリザルトウィンドウは出さない。まず0.45秒で暗転し、黒画面を1.0秒保持してから、星空を0.85秒でフェードインする。星空フェード完了後にゲームオーバー/不可思議リザルトのウィンドウを表示する。
- ゲームオーバー/死亡時の不可思議リザルトでリトライまたは帰還を確定した場合は、ウィンドウを閉じて星空だけを残し、既存の `ScreenTransition` で黒フェードアウトする。黒画面を1.5秒保持してから遷移先をフェードインする。
- ダンジョン内でアプリ終了要求が来た場合も、拠点やタイトルでの終了とは区別し、星を1つ増やす。終了直前の通常セーブを書き換えないよう、星数は通常セーブとは別に `astral_echo.dat` へ即時保存する。
- 結果画面の獲得素材・獲得金額は、ラン初期状態からの差分で集計する。
- 死亡以外で拠点へ戻る時は、出発前の拠点所持品スナップショットへ戻したあと、ラン初期状態からの増分だけを探索成果として合流する。
- ダンジョン入口を調べて帰還した場合は、通常ダンジョンのワープポイント復帰ではなく、そのランを終了して結果画面へ進む。
- 入口帰還、星脈竜撃破、踏破では、ラン中に増えた所持金、素材、バッグ内アイテム、リング上のオブジェクトアイテムを持ち帰れる。
- 初期シャベル、初期松明、初期杖など、ラン開始時点で `runStartInventoryState_` に含まれるアイテムは持ち帰り対象外にする。
- 持ち帰りアイテムはまずバッグへ戻す。バッグが満杯の場合は収納箱へ入れる。収納箱も満杯の場合は、既存の容量制限に従い未収納として扱う。

## 踏破エンディング演出

- 不可思議の迷宮の踏破紙芝居では、最深部を宇宙のような異空間として表示する。
- 不可思議の迷宮の踏破エンディングは、信頼崩壊フラグ `story_trust_broken` が立っていても失敗紙芝居へ分岐しない。
- 周囲の星は `astralEchoStarCount_` の数だけ描画し、過去の死亡やダンジョン中終了によるやり直しが星として残っていたことを示す。
- 最終ページでは周囲の星を残したまま、中央に踏破によって完成した大きな星座を描画する。
