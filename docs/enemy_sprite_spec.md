# 敵スプライト仕様

敵画像は `EnemyImageRenderer` で読み込み、通常描画、捕獲演出、図鑑や開発用プレビューで同じ描画経路を使う。

## 共通仕様

- 敵スプライトは行で向き、列でアニメーションフレームを表す。
- 向きは下、左、右、上の4方向を使う。
- 実際の行番号、列数、フレーム数、アニメーション速度は敵ごとの `EnemySpriteSheetSpec` で決める。
- 描画時の向きは `Enemy::facingAngle` から決める。明示的な `directionOverride` がある場合はそちらを優先する。
- 移動アニメーションは `Enemy::velocity` が十分大きい、または `Enemy::jumpActive` のときに使う。それ以外は待機アニメーションを使う。
- ヒットフラッシュ、状態異常の色、選択アウトラインはスプライト仕様に関係なく共通処理で適用する。敵スプライトの通常アウトラインは描画しない。
- 本体、影、ミニマップマーカーは `enemyVisible()` の結果に従い、`bossAction.hidden` 中は描画しない。

## 通常敵

- 画像パスは `assets/enemies/en_<画像番号>.png`。
- シートは2列x4行。
- 行は上から順に下、左、右、上。
- 待機と移動は同じ行を使い、2フレームを `10 / 60` 秒ごとに切り替える。
- 通常サイズ倍率は `1.0`、ボスとして描画される場合の倍率は `1.35`。

## ボス1 星くずモグラ

- 画像パスは `assets/enemies/boss_1.png`。
- シートは6列x8行。
- 1フレームは現在の画像では240x240。
- 行は上から順に、下待機、下歩行、左待機、左歩行、右待機、右歩行、上待機、上歩行。
- 各アニメーションは6フレームを `24 / 60` 秒ごとに切り替える。ただし突進中の歩行アニメーションだけ `8 / 60` 秒ごとに切り替える。
- 左右は別行を使い、左右反転では代用しない。
- 表示倍率は `0.84`。240x240フレームを約200pxのボス表示として扱う。
- 行動サイクル開始時は `Approach` フェーズに入り、1.5～3.0秒のランダム時間だけ低速でプレイヤーへ歩く。
- 潜りフェーズ開始時は `StardustMoleDiveJumpSeconds` の短い潜りジャンプを表示し、ジャンプ完了時に `bossAction.hidden` を有効にする。
- `bossAction.hidden` 中は敵本体、影、ミニマップマーカーを描画しない。
- 出現開始時にその瞬間のプレイヤー位置へ突進方向を固定し、着地後の突進直前には再照準しない。
- 突進フェーズは `StardustMoleChargeSpeed` を維持し、`StardustMoleChargeSeconds = 2.40` 秒で距離を伸ばす。
- 壁衝突後のスタンは `StardustMoleStunSeconds = 2.20` 秒とし、スタン中は混乱状態と同じ頭上の星エフェクトを表示する。
- 実戦中の弱点表示は判定円や輪郭線で囲わず、弱点中心の周辺に青白い小粒子と短い光筋を決定的な手続き描画で漂わせる。弱点の当たり判定円はロジックと当たり判定編集用にのみ使う。
- 潜り完了時と出現開始時の土煙には、壁破壊と同じ `spawnTileBreak` の土ガレキを音なし、範囲2倍、ガレキ量2倍で重ねる。
- 着地時にも土煙を出すが、ガレキは重ねない。
- 星くずモグラのボス部屋は、ボス部屋半径 + 余白の固定光源をボススポーン地点に置き、部屋全体を明るく保つ。

## Hot Reload

- `assets/enemies/*.png` は画像キャッシュを無効化して差し替えを反映する。
