# 敵スプライト仕様

敵画像は `EnemyImageRenderer` で読み込み、通常描画、捕獲演出、図鑑や開発用プレビューで同じ描画経路を使う。

## 共通仕様

- 敵スプライトは行で向き、列でアニメーションフレームを表す。
- 向きは下、左、右、上の4方向を使う。
- 実際の行番号、列数、フレーム数、アニメーション速度は敵ごとの `EnemySpriteSheetSpec` で決める。
- 描画時の向きは `Enemy::facingAngle` から決める。明示的な `directionOverride` がある場合はそちらを優先する。
- 移動アニメーションは `Enemy::velocity` が十分大きい、または `Enemy::jumpActive` のときに使う。それ以外は待機アニメーションを使う。
- ヒットフラッシュと状態異常の色はスプライト仕様に関係なく共通処理で適用する。敵スプライトは共通描画オプションで黒2pxのアウトラインを描画する。
- 本体、影、ミニマップマーカーは `enemyVisible()` の結果に従い、`bossAction.hidden` 中は描画しない。
- ボス敵の基礎ステータスと `Enemies` シート運用は `docs/boss_enemy_data_spec.md` に従う。

## 通常敵

- 画像パスは `assets/enemies/en_<画像番号>.png`。
- シートは2列x4行。
- 行は上から順に下、左、右、上。
- 待機と移動は同じ行を使い、2フレームを `10 / 60` 秒ごとに切り替える。
- 通常サイズ倍率は `1.0`、ボスとして描画される場合の倍率は `1.35`。

## ボス1 星くずモグラ

- 画像パスは `assets/enemies/boss_1.png`。
- シートは6列x6行。
- 1フレームは現在の画像では240x240。
- 行は上から順に、下待機、下歩行、左待機、左歩行、上待機、上歩行。
- 右向きは左向き行を左右反転して使う。これはボス画像共通の向き運用とする。
- 各アニメーションは6フレームを `24 / 60` 秒ごとに切り替える。ただし突進中の歩行アニメーションだけ `8 / 60` 秒ごとに切り替える。
- 表示倍率は `0.84`。240x240フレームを約200pxのボス表示として扱う。
- 行動サイクル開始時は `Approach` フェーズに入り、1.5～3.0秒のランダム時間だけ低速でプレイヤーへ歩く。
- 潜りフェーズ開始時は `StardustMoleDiveJumpSeconds` の短い潜りジャンプを表示し、ジャンプ完了時に `bossAction.hidden` を有効にする。
- `bossAction.hidden` 中は敵本体、影、ミニマップマーカーを描画しない。
- 出現開始時にその瞬間のプレイヤー位置へ突進方向を固定し、着地後の突進直前には再照準しない。
- 突進フェーズは `StardustMoleChargeSpeed` を維持し、`StardustMoleChargeSeconds = 2.40` 秒で距離を伸ばす。
- 壁衝突後のスタンは `StardustMoleStunSeconds = 2.20` 秒とし、スタン中は混乱状態と同じ頭上の星エフェクトを表示する。
- 実戦中の弱点表示は判定円や輪郭線で囲わず、弱点中心の周辺に青白い小粒子と短い光筋を決定的な手続き描画でゆっくり漂わせる。粒子は小さめ、明滅と移動は長周期にして、弱点の当たり判定円はロジックと当たり判定編集用にのみ使う。
- 潜り完了時と出現開始時の土煙には、壁破壊と同じ `spawnTileBreak` の土ガレキを音なし、範囲2倍、ガレキ量2倍で重ねる。
- 着地時にも土煙を出すが、ガレキは重ねない。
- 星くずモグラのボス部屋は、ボス部屋半径 + 余白の固定光源をボススポーン地点に置き、部屋全体を明るく保つ。

## ボス2 ジャンクラブ

- 画像パスは `assets/enemies/boss_2.png`。
- シートは6列x9行。
- 1フレームは現在の画像では400x400。
- 行は方向ごとに3行ずつ使う。上から順に、下待機、下歩行、下攻撃、左待機、左歩行、左攻撃、上待機、上歩行、上攻撃。
- 右向きは左向き行を左右反転して使う。
- 待機と歩行は6フレームを `12 / 60` 秒ごとに切り替える。
- ハサミ攻撃は6フレームを順に表示し、表示時間は `9 / 60`, `18 / 60`, `54 / 60`, `6 / 60`, `6 / 60`, `80 / 60` 秒とする。攻撃中は最終フレーム到達後にループしない。
- ハサミ攻撃中の画像位置は、攻撃方向へフレームごとに `-5`, `-8`, `-9`, `48`, `96`, `108` pxずらす。
- ハサミ攻撃3フレーム目の表示中は、4フレームごとに画面X方向へ1px左右に揺らして力をためる表現にする。攻撃方向はこの3フレーム目開始時点から固定し、攻撃終了まで方向転換しない。
- ガラクタ飛ばしの予備動作は各方向の攻撃行を使い、6フレームを各 `12 / 60` 秒で表示する。ハサミ攻撃用の位置ずらしと揺れは使わない。
- 表示倍率は `0.72`。400x400フレームを約288pxのボス表示として扱う。
- リングガードのガラクタはHP割合に応じて8～12個生成し、各ガラクタのHPは40。ガラクタが存在しない状態が `300～420 / 60` 秒続くと次のリングガードを生成する。
- リングガード中のガラクタは自転速度をランダムに持ち、`-120～-60` または `60～120` deg/sec の範囲で回転する。
- ガラクタHPが0になると本体へ直線移動し、本体に当たったあと跳ね返って弧を描き、落下付近でフェードアウトする。
- 弱点は頭部にあり、回転中のガラクタが1つもないときだけ露出する。
- 旧投げ攻撃、転倒、復帰は使わない。
- ガラクタ生成から約12秒経過しても回転中のガラクタが残り、かつ他の攻撃中でない場合はガラクタ飛ばしへ遷移する。残っているガラクタから、その瞬間にプレイヤーへ最も近いものを12フレーム間隔で選び、プレイヤー方向へ高速直線発射する。発射音は旧投げ攻撃と同じものを使う。

## Hot Reload

- `assets/enemies/*.png` は画像キャッシュを無効化して差し替えを反映する。
