# BGM素材の準備とループ設定

## 方針

- `BGM素材` のMP3は原本として変更しない。
- ゲーム用音源は `assets/audio/bgm` に48 kHz、16-bit PCM、ステレオのWAVとして生成する。
- 再生用ファイル名とcue IDは小文字のASCIIだけで構成し、正式タイトルはUnicode文字列として別に保持する。
- 正式タイトルの正データは `assets/audio/audio_manifest.tsv` の `display_name` とする。WAVの `title` メタデータにも同じ値を複製するが、ソフトごとにWAVメタデータの表示対応が異なるため、ゲームはメタデータを直接読まない。
- WAV全体は切り詰めない。イントロや終結部を残したまま、マニフェストのフレーム位置で反復区間を指定する。
- 曲の用途（タイトル、拠点、ダンジョン1～4、ボス、ラスボス、エンディング）は音源準備とは分離する。BGM編集画面の左側には用途cueだけを表示し、右側のWAV候補から選曲する。`bgm.asset.*` cueは素材の正式タイトルとループ設定を保持する管理用データであり、用途一覧には表示しない。登録済み素材を用途cueへ適用すると、その素材のループ開始・終了・クロスフェード設定も自動で引き継ぐ。

## ファイルと責務

- `tools/bgm_materials.tsv`: 元ファイル名、出力名、cue ID、正式タイトル、ループ判断の正データ
- `tools/prepare_bgm_assets.ps1`: WAV生成と一括検証
- `assets/audio/audio_manifest.tsv`: ゲームが読む音量、表示名、ループフレーム
- `src/engine/Audio.cpp`: 指定区間の反復、短いクロスフェード、UTF-8パス、表示名の保持

BGMのPCMデータは起動時に20曲すべてを展開せず、最初に再生するときに読み込む。別のBGMへ移った後は、フェード中の音声だけを共有バッファで保持し、使用しなくなったBGMのキャッシュを解放する。これによりWAVの無圧縮品質を保ちながら、全曲分の約1.1 GBを常駐させない。

正式タイトルは、英語の元ファイル名では拡張子を外して `_` を半角スペースへ変換した文字列、日本語の元ファイル名では拡張子を外した文字列を使用している。先頭の `_` は空白として残さず除去する。日本語曲の英語ファイル名は自動翻訳せず、`bgm_materials.tsv` の明示的な対応表で固定する。

## 再生成と検証

初回生成、または既存の20ファイルを意図して置き換える場合:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\prepare_bgm_assets.ps1 -Force
```

既存WAV、正式タイトル、形式、ループ範囲、マニフェストとの一致だけを検証する場合:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\prepare_bgm_assets.ps1 -VerifyOnly
```

ツールは次を検査する。

- 元MP3が過不足なく対応表へ登録されていること
- 出力名とcue IDがASCIIの規則に従い、重複していないこと
- 出力が48 kHz、16-bit PCM、ステレオであること
- WAVの `title` が `display_name` と完全一致すること
- ループ開始、終了、クロスフェードが音声フレームの範囲内にあること
- `audio_manifest.tsv` の対象20行が対応表と一致すること

変換は一時ディレクトリへ全曲を生成・検証してから、対応表に載っている出力だけを移動する。途中で失敗した場合、既存WAVは置き換えない。

## マニフェストのループ列

- `loop_start_frame`: 初回再生後に戻る位置。0は先頭。
- `loop_end_frame`: ここへ到達する直前までを再生して戻る位置。0はWAV終端。
- `loop_crossfade_frames`: 終端側と開始側を重ねる長さ。0は、解析で同じ周期を確認できた自然な境界に使用する。

すべてゲームの出力レートである48 kHz基準のフレーム数で、ステレオの左右1組を1フレームと数える。秒からフレームへの変換は `秒 × 48000` である。

クロスフェード中は終端側から開始側へ線形に移行し、反復後はすでに重ねた開始側フレームを重複再生しない。これによりイントロは最初の一度だけ再生でき、MP3由来の微小な位相差や境界クリックも抑えられる。

## 現在の判断

`First village` は50.5秒で切ると終端前の強いフレーズを途中で失うため、WAV終端まで再生し、末尾1秒の減衰と先頭をクロスフェードする。

`A letter`、`Dot Snow`、`God only knows`、`In the Ruins`、`Small Cave`、`月光蝶` は、ユーザー判断によりWAV終端から先頭へ戻す全体ループとしている。

`Puppet Skeleton` は約1分44.59秒、ピアノだけの終結部へ切り替わる直前から先頭へ戻す。`Vivid Spooky` は約1分59.25秒、ファミコン音だけの終結部へ切り替わる地点から先頭へ戻す。

そのほか、同じ演奏周期を音響フィンガープリントで確認できた曲は、その一致区間または周期を使用している。減衰や編成差があり完全一致しない曲は、終結部を除外し、短いクロスフェードで接続している。各数値と判断理由は `bgm_materials.tsv` に残す。

## 今後の調整手順

1. `BGM素材` にMP3を追加する。
2. `bgm_materials.tsv` に1行追加し、ASCII出力名、cue ID、正式タイトルを決める。
3. 波形、スペクトログラム、反復する編曲区間を確認し、秒単位の開始・終了候補を書く。
4. `prepare_bgm_assets.ps1 -Force` でWAVを生成する。
5. ツールが表示するフレーム数を `audio_manifest.tsv` の対象cueへ反映する。
6. 境界を試聴する。クリックだけなら10～30 ms程度のクロスフェード、編成の減衰をなじませる場合だけ長めのクロスフェードを使う。
7. `prepare_bgm_assets.ps1 -VerifyOnly` とゲームのBGM編集画面で最終確認する。

ループ点を変更してもWAVの再変換は必須ではない。正式タイトル、出力形式、元音源が変わらない場合は、`bgm_materials.tsv` と `audio_manifest.tsv` のフレーム値を同期すればよい。
